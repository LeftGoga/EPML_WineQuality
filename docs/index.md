# Wine Quality ML Project

Добро пожаловать в документацию проекта по предсказанию качества вина!

## Описание проекта

Проект для анализа и моделирования качества вина на основе датасета Wine Quality. Проект использует машинное обучение для предсказания качества вина на основе его физико-химических свойств.

## Основные возможности

- 🔬 **Экспериментирование**: Поддержка различных алгоритмов машинного обучения (Random Forest, Gradient Boosting, MLP)
- 📊 **Трекинг экспериментов**: Интеграция с ClearML для отслеживания экспериментов и метрик
- 🔄 **Пайплайны**: Автоматизированные пайплайны для обучения и оценки моделей
- 📈 **Визуализация**: Автоматическая генерация графиков и отчетов
- 🚀 **Развертывание**: Готовые конфигурации для Docker и CI/CD

## Быстрый старт

```bash
# Установка зависимостей
make install

# Запуск обучения
make run

# Запуск Streamlit приложения
make streamlit
```
