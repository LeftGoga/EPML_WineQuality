# Отчеты об экспериментах

Здесь собраны отчеты об экспериментах проекта.

## Последний отчет

👉 **[Последний отчет об эксперименте](experiment_report.md)** - содержит детальную информацию о последнем выполненном эксперименте, включая метрики, параметры и визуализации.

## Автоматически сгенерированные отчеты

Отчеты генерируются автоматически после каждого эксперимента и сохраняются в директории `hw_reports/`.

## Структура отчета

Каждый отчет содержит:

- **Метрики**: Accuracy, F1-score, и другие метрики
- **Графики**: Визуализации результатов
- **Сравнительные таблицы**: Сравнение различных экспериментов
- **Параметры**: Параметры модели и обучения

## Просмотр отчетов

Отчеты доступны в формате Markdown в директории `hw_reports/`:

- `HW1.MD` - Отчет 1
- `HW2.MD` - Отчет 2
- `HW3.MD` - Отчет 3
- `HW4.MD` - Отчет 4
- `HW5.MD` - Отчет 5 (ClearML интеграция)

## Генерация отчетов

Отчеты генерируются автоматически через скрипт `scripts/generate_experiment_report.py`.

Для ручной генерации:

```bash
python scripts/generate_experiment_report.py \
    --experiment-id <id> \
    --output hw_reports/HW6.MD
```
