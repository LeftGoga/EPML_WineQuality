# Документация проекта

Эта директория содержит исходники документации проекта Wine Quality ML.

## Структура

- `index.md` - Главная страница
- `quickstart.md` - Быстрый старт
- `installation.md` - Установка
- `deployment.md` - Развертывание
- `examples.md` - Примеры использования
- `architecture.md` - Архитектура проекта
- `api/` - API документация
- `experiments/` - Отчеты об экспериментах

## Генерация документации

### Локальная разработка

```bash
# Установка зависимостей
poetry install

# Запуск локального сервера
poetry run mkdocs serve

# Открыть в браузере: http://127.0.0.1:8000
```

### Сборка документации

```bash
# Сборка статических файлов
poetry run mkdocs build

# Результат будет в директории site/
```

## Публикация

Документация автоматически публикуется на GitHub Pages при push в ветку `main` через GitHub Actions.

## Добавление новой страницы

1. Создайте файл `.md` в соответствующей директории
2. Добавьте ссылку в `mkdocs.yml` в секцию `nav`
3. Зафиксируйте изменения в git
