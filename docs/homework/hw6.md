
## 3. Отчеты об экспериментах (2 балла)

### a) Создание отчетов об экспериментах в формате Markdown

Реализован скрипт `src/wine_quality/generate_experiment_report.py` для автоматической генерации отчетов об экспериментах из ClearML.

Скрипт выполняет:
- Загрузку данных эксперимента из ClearML по ID
- Генерацию Markdown отчета с параметрами и метриками
- Поддержку сравнения нескольких экспериментов

Примеры использования:
```bash
make report TASK_ID=xxx                    # Отчет по эксперименту
make report-comparison COMPARISON=id1 id2   # Сравнение экспериментов
make report-latest                          # Последние два эксперимента
```

### b) Добавление графиков и визуализаций результатов

Скрипт автоматически генерирует графики сравнения метрик между экспериментами с использованием matplotlib и seaborn. Поддерживается загрузка графиков из ClearML и конвертация Plotly графиков в изображения.

### c) Создание сравнительных таблиц экспериментов

Реализованы функции для создания таблиц параметров, метрик и сравнительных таблиц для нескольких экспериментов с выделением лучших значений.

### d) Настройка автоматической генерации отчетов

Настроена автоматическая генерация отчетов через команды Makefile. Отчеты сохраняются в `docs/experiment_report.md` и автоматически включаются в MkDocs документацию, что триггерит пересборку и публикацию на GitHub Pages.
